# Contributing

Thanks for your interest in Cozy Reads.

## Getting started

See the [local setup](README.md#local-setup) section of the README. `npm run dev` with `/?demo=1` runs the app on sample data without a Supabase project.

Before opening a pull request, make sure these pass:

```bash
npm run lint
npm run build
```

Keep changes focused, and match the style of the surrounding code.
